# Drive

Team document and file hub built with Astro.

This repository is the storage and presentation layer for shared team documents, PDFs, JSON, DOCX files, datasets, images, and other project assets.

## Structure

- `src/` — Astro application
- `public/` — static assets
- `data/` — structured application metadata
- `documents/` — shared documents and project files

Supabase will be connected later for authentication, metadata, storage, and team access control.
